CHROME EXTENSION ICON FIX INSTRUCTIONS
======================================

The Chrome extension is currently configured to use a single icon file named "default_icon.png". 
Follow these steps to create and use this icon:

1. Open the "default_icon.html" file in your browser by double-clicking it
2. Click the "Download Icon" button to download the default_icon.png file
3. Move the downloaded default_icon.png file to the chrome-extension directory (same level as manifest.json)
4. The extension should now load without the icon error

For proper icons with multiple sizes:
-------------------------------------
To create proper icon files with multiple sizes (16px, 48px, 128px), you can:

1. Use an image editor like Photoshop, GIMP, or an online tool to create icons
2. Create three PNG files named:
   - icon16.png (16x16 pixels)
   - icon48.png (48x48 pixels)
   - icon128.png (128x128 pixels)
3. Place these files in the "chrome-extension/images/" directory
4. Update the manifest.json file to use these icons:

"action": {
  "default_popup": "popup.html",
  "default_icon": {
    "16": "images/icon16.png",
    "48": "images/icon48.png",
    "128": "images/icon128.png"
  }
},
"icons": {
  "16": "images/icon16.png",
  "48": "images/icon48.png",
  "128": "images/icon128.png"
}
